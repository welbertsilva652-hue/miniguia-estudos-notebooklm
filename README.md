# Caderno Temático: Inteligência Artificial com NotebookLM
## Sobre o Projeto
 Este projeto apresenta um caderno temático sobre Inteligência Artificial desenvolvido com o NotebookLM. O objetivo é organizar, explorar e consolidar conhecimentos sobre o tema por meio de fontes selecionadas, engenharia de prompts e produção de um miniguia de estudo 
### Contexto
A Inteligência Artificial vem se tornando uma ferramenta importante para estudos, trabalho e produção de conhecimento. Este projeto foi desenvolvido para explorar o uso da IA de forma prática, utilizando o Notebook LM como ferramenta de apoio à pesquisa, organização e compreensão de informações.
### Objetivos 
*.Compreender conceitos fundamentais de Inteligência Artificial.
*. Explorar o uso do Notebook LM para estudos e pesquisas.
*. Aprender a selecionar e organizar fontes confiáveis. 
*. Desenvolver e testar diferentes estratégias de engenharia de prompts.
*. Registrar erros, dificuldades e melhorias durante o processo. 
*. Criar um miniguia de estudo que possa ser consultado posteriormentetudo
