Engenharia de Prompts e Cicatrizes - NotebookLM

Prompts Utilizados e Aprendizados

1. Prompt Inicial (Básico)
Prompt usado:  
"Resuma o conteúdo principal sobre Inteligência Artificial"

Resultado: Resumo muito genérico e superficial.  
Aprendizado: Prompts vagos geram respostas fracas.

2. Prompt Melhorado (Específico)
Prompt usado:  
"Com base em todas as fontes carregadas, crie um resumo estruturado sobre Inteligência Artificial, separando em definição, tipos principais e aplicações práticas."

Resultado: Muito melhor, com estrutura clara.  
Melhoria: Adicionar "com base em todas as fontes" e pedir estrutura específica.

3. Prompt Avançado (Usado no projeto)
Prompt usado:  
"Atue como um professor especialista. Usando apenas as fontes enviadas, explique de forma clara e didática o que é o NotebookLM, suas principais funcionalidades e como ele pode ser usado para estudar Inteligência Artificial. Inclua exemplos práticos."

Resultado: Excelente. Resposta bem organizada e útil.

4. Prompt para Mapa Mental
Prompt usado:  
"Crie um mapa mental textual sobre os conceitos principais de Inteligência Artificial e NotebookLM."

5. Prompt para Podcast
Prompt usado:  
"Gere um áudio overview explicando como usar o NotebookLM para estudar sobre IA."

Melhores Práticas Descobertas
Sempre usar "baseado apenas nas fontes carregadas"
Pedir formato específico (resumo, tabela, mapa mental)
Definir o papel da IA ("Atue como um professor...")
Ser específico sobre o que quer no resultado
